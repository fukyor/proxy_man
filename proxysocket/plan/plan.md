  2. 订阅用户流量（客户端 → 服务端）

  连接建立后发送订阅消息，topics 数组中包含 "user_traffic" 即可激活推送。

  {
    "action": "subscribe",
    "topics": ["user_traffic"]
  }

  也可与其他 topic 组合订阅：

  {
    "action": "subscribe",
    "topics": ["traffic", "connections", "logs", "user_traffic"],
    "logLevel": "INFO"
  }

  可用 topics 列表：

  ┌────────────────┬─────────────────────────────────┐
  │     topic      │              说明               │
  ├────────────────┼─────────────────────────────────┤
  │ traffic        │ 全局实时带宽速率（bytes/s）     │
  ├────────────────┼─────────────────────────────────┤
  │ connections    │ 连接列表快照                    │
  ├────────────────┼─────────────────────────────────┤
  │ logs           │ 代理运行日志                    │
  ├────────────────┼─────────────────────────────────┤
  │ mitm_detail    │ MITM 请求/响应详情              │
  ├────────────────┼─────────────────────────────────┤
  │ intercept_logs │ 拦截规则命中日志                │
  ├────────────────┼─────────────────────────────────┤
  │ user_traffic   │ 按 IP+Host 的流量累计（本模块） │
  └────────────────┴─────────────────────────────────┘

  3. 服务端推送格式（服务端 → 客户端）

  推送间隔：每 2 秒一次。若当前无任何流量记录则跳过本轮推送。

  {
    "type": "user_traffic",
    "data": [
      {
        "ip": "192.168.1.100",
        "online": true,
        "totalUp": 1234567,
        "totalDown": 9876543,
        "hosts": [
          {
            "host": "google.com",
            "up": 500000,
            "down": 3000000
          },
          {
            "host": "github.com",
            "up": 734567,
            "down": 6876543
          }
        ]
      },
      {
        "ip": "10.0.0.5",
        "online": false,
        "totalUp": 88192,
        "totalDown": 512000,
        "hosts": [
          {
            "host": "example.com",
            "up": 88192,
            "down": 512000
          }
        ]
      }
    ]
  }

  字段说明：

  ┌─────────────────────┬────────┬────────────────────────────────────┐
  │        字段         │  类型  │                说明                │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ type                │ string │ 固定值 "user_traffic"              │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data                │ array  │ 所有客户端 IP 的流量列表           │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data[].ip           │ string │ 客户端 IP（纯 IP，不含端口）       │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data[].totalUp      │ int64  │ 该 IP 所有 Host 的上行累计字节数   │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data[].totalDown    │ int64  │ 该 IP 所有 Host 的下行累计字节数   │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data[].hosts        │ array  │ 按 Host 拆分的明细列表             │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data[].hosts[].host │ string │ 目标域名（纯域名，不含端口）       │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data[].hosts[].up   │ int64  │ 该 Host 上行累计字节数（含请求头） │
  ├─────────────────────┼────────┼────────────────────────────────────┤
  │ data[].hosts[].down │ int64  │ 该 Host 下行累计字节数（含响应头） │
  └─────────────────────┴────────┴────────────────────────────────────┘

  统计范围说明：
  - up = 请求头 + 请求体（覆盖 HTTP、HTTPS Tunnel、HTTPS MITM 全部模式）
  - down = 响应头 + 响应体
  - 数值为累计总量（非速率），单位 bytes，进程重启后归零

  4. 断开指定 IP 所有连接（客户端 → 服务端）

  {
    "action": "closeUserConnections",
    "ip": "192.168.1.100"
  }

  字段说明：

  ┌────────┬────────┬──────┬─────────────────────────────────┐
  │  字段  │  类型  │ 必填 │              说明               │
  ├────────┼────────┼──────┼─────────────────────────────────┤
  │ action │ string │ 是   │ 固定值 "closeUserConnections"   │
  ├────────┼────────┼──────┼─────────────────────────────────┤
  │ ip     │ string │ 是   │ 要断开的客户端纯 IP，为空则忽略 │
  └────────┴────────┴──────┴─────────────────────────────────┘

  行为： 遍历当前所有活跃连接，凡 RemoteAddr 解析出的 IP 匹配 ip
  字段，立即关闭该连接并从连接表移除。父隧道及其所有子连接均会被关闭。

  5. 相关 Action 全览

  ┌──────────────────────┬──────────┬────────────────────────────┐
  │        action        │ 必填参数 │            说明            │
  ├──────────────────────┼──────────┼────────────────────────────┤
  │ subscribe            │ topics[] │ 订阅/变更推送主题          │
  ├──────────────────────┼──────────┼────────────────────────────┤
  │ closeUserConnections │ ip       │ 断开指定 IP 的全部连接     │
  ├──────────────────────┼──────────┼────────────────────────────┤
  │ closeConnection      │ id (int) │ 断开单条连接（含其子连接） │
  ├──────────────────────┼──────────┼────────────────────────────┤
  │ closeAllConnections  │ 无       │ 断开所有当前连接           │
  └──────────────────────┴──────────┴────────────────────────────┘

  6. 典型前端接入示例（伪代码）

  const ws = new WebSocket('ws://localhost:8080/start?token=your-secret')

  ws.onopen = () => {
    // 订阅用户流量监控
    ws.send(JSON.stringify({
      action: 'subscribe',
      topics: ['user_traffic']
    }))
  }

  ws.onmessage = (event) => {
    const msg = JSON.parse(event.data)
    if (msg.type === 'user_traffic') {
      // msg.data 是按 IP 分组的流量快照数组
      updateUserTrafficTable(msg.data)
    }
  }

  // 断开指定 IP
  function blockUser(ip) {
    ws.send(JSON.stringify({
      action: 'closeUserConnections',
      ip: ip
    }))
  }
